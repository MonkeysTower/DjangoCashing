# DjangoCaching

This project demonstrates the use of various caching backends in Django.

## Requirements

1. Python 3.11 or greater
2. [Poetry](https://python-poetry.org/docs/) for dependency management

## Install

1. Clone repository
```bash
git clone https://github.com/MonkeysTower/DjangoCashing.git
cd DjangoCashing

```
2. Install dependencies
```bash
poetry install
```
3. Activate enviroment
```bash
poetry shell
```
4. Apply database migrations
```bash
python manage.py migrate
```
5. Run server
```bash
python manage.py runserver
```
